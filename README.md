## Cognitive-Load-Aware Student Scheduler
**CS 6750: Human-Computer Interaction, Georgia Tech** (team project, 4 members)

A scheduling system that helps students decide what to work on next, not just list what they have to do. The team ran surveys (21 students), six semi-structured interviews, and a heuristic evaluation of Google Calendar, then built and tested three prototypes: AI-assisted task breakdown, a cognitive heatmap, and gamification. The final design combines a gamified scheduler with task breakdown and workload visualization.

My contributions:
- Designed **Prototype B: Cognitive Heatmap**, a cognitive-load-aware calendar with weekly, monthly, and daily views that show mental workload alongside deadlines
- Built all data visualizations for the evaluation analysis in Python
- Co-wrote sections of the report
